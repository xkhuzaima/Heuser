About This Portfolio

Portfolio OS

Version 8.0 · Homework 8 Edition

This portfolio has no header or menu to scroll through. It's a small desktop that runs in your browser, and every section lives in its own app. Open apps from the Dock, then drag, stack, zoom or minimise their windows however you like. I built it with plain HTML, CSS and JavaScript so it feels like software you explore, not a page you read top to bottom.
